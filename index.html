Air Strings

Draw strings of light in midair and play them with your hands.

  1. Pinch thumb + index to set the first point, move, and release to set the second point. A string appears between them.
  2. Or pinch with both hands to stretch a string between them.
  3. Swipe your index fingertip through a string to pluck it.
  4. Pinch on a string to grab it, pull it, and let go to twang it.

Shorter strings play higher notes. A mouse also works: drag to draw, hover across a string to pluck it, drag a string to pull it.
